Nordstjernen वेब ब्राउझर

Nordstjernen हा C मधील, 2026 मध्ये सुरू झालेला एक स्वतंत्र वेब ब्राउझर आहे, जो HTML आणि CSS मानकांच्या समर्थनावर लक्ष केंद्रित करतो. तो Windows, macOS आणि Linux वर चालतो, आणि Android, FreeBSD, NetBSD व JVM साठीही त्याचे बिल्ड उपलब्ध आहेत. Nordstjernen नॉर्वेमध्ये तयार झाला आहे.

Nordstjernen 1.0.51 प्रकाशित — CSS Typed OM, सामायिक मेमरीसह WebAssembly थ्रेड, लिंकसह PDF निर्यात आणि एक AppImage. रिलीझ नोट्स »

Northstar 1.0.26 प्रकाशित — WebGL 1 आणि 2, व्यवस्थित चालणारे Gmail, सुरक्षा दुरुस्त्या आणि एक AppImage. Northstar विषयी · रिलीझ नोट्स »

Southstar 1.0.11 प्रकाशित — स्ट्रीमिंग HTML पार्सर, लहान DOM आणि रिअल-टाइम Web Audio. Southstar विषयी · रिलीझ नोट्स »

HTML मानक. वर्तन दुसऱ्या ब्राउझरशी नव्हे, तर विभागानुसार मानकाच्या मजकुराशी तुलना करून मोजले जाते: WHATWG HTML मानकातील 141 ओळी पूर्णपणे अंमलात आणल्या आहेत, 31 अंशतः, आणि एकही राहिलेली नाही. तो Web Platform Tests मधील html/, dom/ आणि url/ सबटेस्टपैकी 91.5% आणि css/ पैकी 73.2% उत्तीर्ण करतो (ऑक्टोबर 2026) — पाहा docs/HTML-compatibility.md.

सुरक्षित. प्रत्येक टॅब स्वतःच्या सँडबॉक्स केलेल्या रेंडरर प्रोसेसमध्ये चालतो — Linux वर seccomp + Landlock, macOS वर Seatbelt प्रोफाइल, Windows वर प्रोसेस मिटिगेशन धोरणे. JavaScript किंवा WebAssembly, कोणत्याही इंजिनमध्ये JIT नाही.

मिनिमलिझम. ब्राउझरमध्ये प्रकल्पाच्या स्वतःच्या C कोड आणि हेडरच्या सुमारे 296,000 ओळी आहेत, समाविष्ट बाह्य लायब्ररी आणि आपोआप तयार झालेल्या फाइल्स वगळून — इतके लहान की एक व्यक्ती ते सुरुवातीपासून शेवटपर्यंत वाचून तपासू शकते.

सक्षम. सुरक्षित Rust मधील स्वतःचा HTML5 पार्सर, हीप-सुदृढ QuickJS, थ्रेडसह WebAssembly, CSS Typed OM, WebGL 1 & 2 आणि WebGPU, Service Workers आणि Streams. पृष्ठातच <video> — MPEG-1, WebM, आणि ऑपरेटिंग सिस्टीमच्या डिकोडरद्वारे MP4 — HLS, DASH आणि कॅप्शनसह, शिवाय SMIL ॲनिमेशनसह SVG, MathML आणि PDF.js व्ह्यूअर.

ऑटोमेशन. nordstjernen --mcp स्थानिक एजंटला विंडो वाचू आणि चालवू देतो — परवानगी मिळेपर्यंत बंद, फक्त लूपबॅक, टोकनद्वारे प्रमाणीकृत — आणि --webdriver Selenium व इतर टेस्ट फ्रेमवर्कसाठी W3C WebDriver उपलब्ध करून देतो. ब्राउझरमध्ये स्वतः कोणताही AI सहाय्यक नाही.

प्रिंटिंग. Ctrl+P @media print, @page आणि पेज ब्रेकनुसार पृष्ठाची पाने पाडतो आणि ती ऑपरेटिंग सिस्टीमच्या स्वतःच्या प्रिंट संवादाकडे सोपवतो. --export=pdf:FILE प्रिंटरशिवाय तीच पाने, लिंकसह, PDF मध्ये लिहितो.

वेगवान. web-text-lib, म्हणजे ट्रीमध्ये समाविष्ट Pango फोर्क, शेप केलेला मजकूर वेगवेगळ्या लेआउटमध्ये कॅश करतो आणि तक्त्यांनी भरलेल्या पृष्ठांवर लेआउटचा वेळ 24% ने कमी करतो. HTTP/3 अपग्रेड कनेक्ट टाइमआउटवर अडकण्याऐवजी alt-svc कॅशमधून जातात: Acid3 15.5 ऐवजी 2.2 सेकंदांत लोड होते.

खाजगी. टेलिमेट्री नाही, अपडेट पिंग नाहीत, आणि client hints मध्ये Chrome ऐवजी Nordstjernen चे नाव. थर्ड-पार्टी कुकीज ब्लॉक केल्या जातात, लिंकमधून ट्रॅकिंग पॅरामीटर काढून टाकले जातात, आणि Safe Browsing Google ला फक्त 4-बाइटचा हॅश उपसर्ग पाठवते, पत्ता कधीच नाही.

मुक्त सॉफ्टवेअर. 1.0.28 पासून Nordstjernen दुहेरी परवान्याखाली आहे: तुमच्या पसंतीनुसार GNU GPL, आवृत्ती 3 किंवा नंतरची किंवा Nordstjernen Source License 1.0 अंतर्गत तो वापरा, बदला आणि पुन्हा वितरित करा.

Northstar ब्राउझर

Northstar हा Nordstjernen चा मिनिमलिस्ट भाऊ आहे, GNU GPL, आवृत्ती 3 किंवा नंतरची या परवान्याखाली: एक विंडो, एक पृष्ठ आणि एक प्रोसेस, सुमारे 234,000 ओळींच्या मूळ C कोडमध्ये बनवलेला. त्यात टॅब, प्रति-टॅब रेंडरर प्रोसेस आणि WebGPU नाहीत, पण WebGL 1 आणि 2, स्ट्रीमिंग व्हिडिओ, प्रिंटिंग, PDF.js व्ह्यूअर, WebExtensions, Google Safe Browsing आणि 40 भाषांमधील UI आहेत, आणि Linux वर तो Landlock व seccomp सँडबॉक्समागे चालतो. Linux हा त्याचा मुख्य प्लॅटफॉर्म आहे; तो macOS, BSD प्रणाली आणि Windows वरही चालतो, आणि Windows साठी तो Microsoft Store वर उपलब्ध आहे.

Northstar चे संपूर्ण दस्तऐवजीकरण वाचा » · किंवा तिन्ही ब्राउझर कसे वेगळे आहेत हे पाहण्यासाठी खालील तुलना तक्ता पाहा.

Southstar ब्राउझर

Southstar म्हणजे Rust मध्ये पोर्ट केलेला Nordstjernen, जो चालू ठेवूनच एकेक मॉड्यूल करत रूपांतरित केला गेला: ऑक्टोबर 2026 पासून त्याचा स्वतःचा सर्व कोड Rust मध्ये आहे — 164 crates मध्ये सुमारे 390,000 ओळी — आणि तो फक्त Cargo ने बिल्ड होतो. पृष्ठावरील JavaScript Boa वर चालते, जो JIT नसलेला Rust इंटरप्रिटर आहे आणि संपूर्ण test262 उत्तीर्ण करतो; HTML पार्सिंग, मजकूर लेआउट, TLS आणि WebAssembly सुद्धा Rust मध्ये आहेत. Southstar 1.0.11 Microsoft Store आणि crates.io वर उपलब्ध आहे, आणि त्याचे Linux पॅकेज GitHub वर आहेत; पोर्ट कसा केला गेला ते docs/rust-port.md मध्ये दिले आहे.

Weststar ब्राउझर

Weststar हा कुटुंबातील सर्वात नवीन ब्राउझर आहे, नोव्हेंबर 2026 मध्ये सुरू झालेला: Northstar चा एक फोर्क, ज्यात GTK 4 इंटरफेस आणि Cairo रेंडरर बदलले आहेत. त्याची विंडो SDL3 आहे, आणि पृष्ठे, ब्राउझरचा इंटरफेस आणि मजकूर Weststar चा स्वतःचा 2D रास्टरायझर काढतो; पृष्ठ इंजिन Northstar चेच आहे. तो Linux आणि Windows वर चालतो, GNU GPL, आवृत्ती 3 किंवा नंतरची या परवान्याखाली आहे, आणि सध्या त्यात WebGL, WebGPU, <video> आणि प्रिंटिंग नाहीत. अजून कोणतेही रिलीझ नाही; पोर्टचे काम कसे चालले आहे ते docs/porting-to-sdl.md मध्ये दिले आहे.

Nordstjernen वेब ब्राउझरमधील नवकल्पनांविषयी अधिक वाचा.

तपशील

तीन ब्राउझर, एकच इंजिन परंपरा. Nordstjernen हा प्रमुख मल्टी-टॅब ब्राउझर आहे; Northstar ही GPL परवान्याची मिनिमलिस्ट सिंगल-प्रोसेस आवृत्ती आहे; Southstar हा तोच ब्राउझर Rust मध्ये पुन्हा लिहिलेला आहे. Weststar, Northstar चा SDL3 फोर्क, याचे अजून कोणतेही रिलीझ नाही आणि तो तक्त्यात नाही.

तिन्ही ब्राउझर पाहण्यासाठी तक्ता बाजूला स्वाइप करा.
