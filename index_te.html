Nordstjernen వెబ్ బ్రౌజర్

Nordstjernen అనేది C లో మొదటి నుండి వ్రాయబడిన ఒక వెబ్ బ్రౌజర్, ఇది HTML మరియు CSS ప్రమాణాలకు మద్దతు ఇవ్వడంపై దృష్టి పెడుతుంది. ఇది Windows, macOS మరియు Linux లపై నడుస్తుంది, అలాగే Android, FreeBSD, NetBSD మరియు JVM కోసం కూడా బిల్డ్‌లు ఉన్నాయి. Nordstjernen నార్వేలో నిర్మించబడుతోంది.

HTML ప్రమాణం. ప్రవర్తన మరొక బ్రౌజర్‌తో కాకుండా, విభాగం వారీగా స్పెసిఫికేషన్ పాఠ్యంతో పోల్చి కొలవబడుతుంది: WHATWG HTML స్పెసిఫికేషన్‌లోని 141 అంశాలు పూర్తిగా అమలయ్యాయి, 31 పాక్షికంగా, ఏదీ వదిలివేయబడలేదు. ఇది Web Platform Tests లోని html/, dom/ మరియు url/ సబ్‌టెస్ట్‌లలో 91.5%, css/ లో 73.2% ఉత్తీర్ణత సాధిస్తుంది (అక్టోబర్ 2026) — చూడండి docs/HTML-compatibility.md.

సురక్షితమైనది. ప్రతి ట్యాబ్ దాని స్వంత శాండ్‌బాక్స్ చేయబడిన రెండరర్ ప్రాసెస్‌లో నడుస్తుంది — Linux లో seccomp + Landlock, macOS లో ఒక Seatbelt ప్రొఫైల్, Windows లో ప్రాసెస్ మిటిగేషన్ పాలసీలు. JavaScript ఇంజిన్‌లో గానీ WebAssembly ఇంజిన్‌లో గానీ JIT లేదు.

కనిష్టత్వం. కోర్ ఇంజిన్‌లో ప్రాజెక్ట్ స్వంత C కోడ్ మరియు హెడర్‌లు కలిపి సుమారు 268,000 లైన్లు ఉన్నాయి, చేర్చిన బయటి లైబ్రరీలు మరియు ఆటోమేటిక్‌గా రూపొందిన ఫైల్‌లు కాకుండా — ఒక వ్యక్తి మొదటి నుండి చివరి వరకు చదివి ఆడిట్ చేయగలిగేంత చిన్నది.

సమర్థమైనది. సురక్షిత Rust లో దాని స్వంత HTML5 పార్సర్, హీప్-దృఢీకరించిన QuickJS, WebAssembly, WebGL 1 & 2 మరియు WebGPU, Service Workers మరియు Streams. పేజీలోనే <video> — MPEG-1, WebM, మరియు ఆపరేటింగ్ సిస్టమ్ డీకోడర్‌ల ద్వారా MP4 — HLS, DASH మరియు క్యాప్షన్‌లతో, వీటితో పాటు SMIL యానిమేషన్‌తో SVG, MathML మరియు ఒక PDF.js వ్యూయర్.

ఆటోమేషన్. nordstjernen --mcp ఒక స్థానిక ఏజెంట్‌ను విండోను చదవడానికి, నడపడానికి అనుమతిస్తుంది — అనుమతి ఇచ్చే వరకు ఆఫ్‌లో ఉంటుంది, లూప్‌బ్యాక్ మాత్రమే, టోకెన్‌తో ప్రమాణీకరించబడుతుంది — మరియు --webdriver Selenium మరియు ఇతర టెస్ట్ ఫ్రేమ్‌వర్క్‌ల కోసం W3C WebDriver ను అందిస్తుంది. బ్రౌజర్‌లో స్వయంగా ఏ AI అసిస్టెంట్ లేదు.

ప్రింటింగ్. Ctrl+P పేజీని @media print, @page మరియు పేజ్ బ్రేక్‌ల ప్రకారం పుటలుగా విభజించి, వాటిని ఆపరేటింగ్ సిస్టమ్ స్వంత ప్రింట్ డైలాగ్‌కు అప్పగిస్తుంది. --dump=print:FILE ప్రింటర్ లేకుండానే అవే పుటలను ఒక PDF లోకి వ్రాస్తుంది.

వేగవంతమైనది. web-text-lib, అంటే ట్రీలోనే ఉన్న Pango ఫోర్క్, షేప్ చేసిన టెక్స్ట్‌ను వేర్వేరు లేఅవుట్‌ల మధ్య క్యాష్ చేసి, పట్టికలు ఎక్కువగా ఉన్న పేజీలలో లేఅవుట్ సమయాన్ని 24% తగ్గిస్తుంది. HTTP/3 అప్‌గ్రేడ్‌లు కనెక్ట్ టైమ్‌అవుట్ వద్ద ఆగిపోకుండా alt-svc క్యాష్ ద్వారా జరుగుతాయి: Acid3 15.5 సెకన్లకు బదులు 2.2 సెకన్లలో లోడ్ అవుతుంది.

గోప్యమైనది. టెలిమెట్రీ లేదు, అప్‌డేట్ పింగ్‌లు లేవు, మరియు client hints లో Chrome కాకుండా Nordstjernen పేరే ఉంటుంది. థర్డ్-పార్టీ కుకీలు బ్లాక్ చేయబడతాయి, లింక్‌ల నుండి ట్రాకింగ్ పారామీటర్‌లు తొలగించబడతాయి, మరియు Safe Browsing Google కు కేవలం 4-బైట్ల హ్యాష్ ప్రిఫిక్స్‌ను మాత్రమే పంపుతుంది, చిరునామాను ఎప్పుడూ కాదు.

స్వేచ్ఛా సాఫ్ట్‌వేర్. 1.0.28 నుండి Nordstjernen ద్వంద్వ లైసెన్స్ కలిగి ఉంది: మీ ఎంపిక ప్రకారం GNU GPL, వెర్షన్ 3 లేదా తదుపరిది లేదా Nordstjernen Source License 1.0 కింద దీన్ని ఉపయోగించండి, మార్చండి, పునఃపంపిణీ చేయండి.

Northstar బ్రౌజర్

Northstar అనేది Nordstjernen యొక్క కనిష్టతావాద తోబుట్టువు, GNU GPL, వెర్షన్ 3 లేదా తదుపరిది కింద లైసెన్స్ పొందినది: ఒక విండో, ఒక పేజీ, ఒక ప్రాసెస్, అదే clean-room ఇంజిన్ నుండి సుమారు 219,000 లైన్ల అసలైన C లో నిర్మించబడింది. ఇందులో ట్యాబ్‌లు, ప్రతి-ట్యాబ్ రెండరర్ ప్రాసెస్‌లు, WebGL మరియు WebGPU ఉండవు, కానీ స్ట్రీమింగ్ వీడియో, ప్రింటింగ్, WebExtensions, Google Safe Browsing మరియు 40 భాషలలో UI ఉన్నాయి, Linux లో Landlock మరియు seccomp శాండ్‌బాక్స్ వెనుక నడుస్తుంది. ఇది Linux, macOS మరియు Windows లపై నడుస్తుంది, Windows కోసం ఇది Microsoft Store లో లభిస్తుంది.

Northstar పూర్తి డాక్యుమెంటేషన్ చదవండి » · లేదా మూడు బ్రౌజర్‌లు ఎలా భిన్నంగా ఉంటాయో తెలుసుకోవడానికి క్రింద ఉన్న పోలిక పట్టిక చూడండి.

Southstar బ్రౌజర్

Southstar అనేది Rust కు పోర్ట్ చేయబడిన Nordstjernen, నడుస్తూ ఉండగానే మాడ్యూల్ వారీగా మార్చబడింది: అక్టోబర్ 2026 నుండి దాని స్వంత కోడ్ అంతా Rust లోనే ఉంది — సుమారు 163 crates లో దాదాపు 385,000 లైన్లు — కేవలం Cargo తోనే బిల్డ్ అవుతుంది. పేజీ JavaScript Boa పై నడుస్తుంది, ఇది JIT లేని ఒక Rust ఇంటర్‌ప్రెటర్, test262 మొత్తాన్నీ ఉత్తీర్ణమవుతుంది; HTML పార్సింగ్, టెక్స్ట్ లేఅవుట్, TLS మరియు WebAssembly కూడా Rust లోనే ఉన్నాయి. Southstar 1.0.9 Microsoft Store లోనూ, crates.io లోనూ లభిస్తుంది, దీని Linux ప్యాకేజీలు GitHub లో ఉన్నాయి; పోర్ట్ ఎలా చేశారో docs/rust-port.md లో వివరించబడింది.

Nordstjernen వెబ్ బ్రౌజర్‌లోని ఆవిష్కరణల గురించి మరింత చదవండి.

స్పెసిఫికేషన్‌లు

మూడు బ్రౌజర్‌లు, ఒకే clean-room ఇంజిన్ వంశం. Nordstjernen ప్రధాన మల్టీ-ట్యాబ్ బ్రౌజర్; Northstar GPL లైసెన్స్ కలిగిన కనిష్టతావాద సింగిల్-ప్రాసెస్ ఎడిషన్; Southstar అదే బ్రౌజర్, Rust లో తిరిగి వ్రాయబడింది.

మూడు బ్రౌజర్‌లనూ చూడటానికి పట్టికను పక్కకు స్వైప్ చేయండి.
