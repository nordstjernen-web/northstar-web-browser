Nordstjernen ウェブブラウザ

Nordstjernen は C 言語でゼロから書かれたウェブブラウザで、HTML と CSS の標準への対応に重点を置いています。Windows、macOS、Linux で動作し、Android、FreeBSD、NetBSD、JVM 向けのビルドもあります。Nordstjernen はノルウェーで開発されています。

HTML 標準。動作は他のブラウザではなく、仕様の本文を基準に章ごとに検証しています。WHATWG HTML 仕様の項目のうち 141 件を完全に実装、31 件を部分的に実装しており、未実装はありません。合格率は 91.5% で、対象は Web Platform Tests の html/、dom/、url/ のサブテスト、css/ は 73.2% です（2026年10月時点）— 詳しくは docs/HTML-compatibility.md をご覧ください。

安全。各タブはそれぞれサンドボックス化されたレンダラープロセスで動作します — Linux では seccomp + Landlock、macOS では Seatbelt プロファイル、Windows ではプロセス緩和ポリシーを使用します。JavaScript エンジンにも WebAssembly エンジンにも JIT はありません。

ミニマリズム。コアエンジンは、同梱のライブラリと生成されたアセットを除くと、プロジェクト独自の C コードとヘッダーで約 268,000 行 — 1 人で最初から最後まで読み通し、監査できる規模です。

高機能。安全な Rust で書かれた独自の HTML5 パーサー、ヒープを堅牢化した QuickJS、WebAssembly、WebGL 1 & 2 と WebGPU、Service Workers、Streams を搭載。インラインの <video> — MPEG-1、WebM、そして OS のデコーダーを利用した MP4 — は HLS、DASH、字幕に対応し、さらに SMIL アニメーション付きの SVG、MathML、PDF.js ビューアーも備えています。

自動化。nordstjernen --mcp を使うと、ローカルのエージェントがウィンドウを読み取って操作できます — 許可するまで無効、ループバックのみ、トークン認証付き — また --webdriver は Selenium などのテストフレームワーク向けに W3C WebDriver を提供します。ブラウザ自体には AI アシスタントはありません。

印刷。Ctrl+P を押すと、@media print、@page、改ページに従ってページを分割し、OS 標準の印刷ダイアログに渡します。--dump=print:FILE を使えば、プリンターがなくても同じページを PDF に書き出せます。

高速。ツリー内で管理している Pango のフォーク web-text-lib は、シェーピング済みのテキストをレイアウトをまたいでキャッシュし、表の多いページでレイアウト時間を 24% 短縮します。HTTP/3 へのアップグレードは接続タイムアウトで止まることなく alt-svc キャッシュを経由するため、Acid3 は 15.5 秒ではなく 2.2 秒で読み込まれます。

プライバシー。テレメトリなし、アップデート確認の通信なし、クライアントヒントで名乗るのも Chrome ではなく Nordstjernen です。サードパーティ Cookie はブロックされ、リンクからはトラッキングパラメーターが除去され、セーフ ブラウジングが Google に送るのは 4 バイトのハッシュプレフィックスだけで、アドレスは決して送りません。

フリーソフトウェア。1.0.28 以降、Nordstjernen はデュアルライセンスです。GNU GPL バージョン 3 以降、または Nordstjernen Source License 1.0 のいずれかを選んで、使用、改変、再配布できます。

Northstar ブラウザ

Northstar は Nordstjernen のミニマルな兄弟ブラウザで、GNU GPL バージョン 3 以降でライセンスされています。1 つのウィンドウ、1 つのページ、1 つのプロセスで構成され、同じクリーンルームのエンジンから約 219,000 行のオリジナルの C コードで作られています。タブ、タブごとのレンダラープロセス、WebGL、WebGPU は省かれていますが、ストリーミング動画、印刷、WebExtensions、Google セーフ ブラウジング、40 言語の UI は備えており、Linux では Landlock と seccomp のサンドボックス内で動作します。Linux、macOS、Windows で動作し、Windows 版は Microsoft Store で入手できます。

Southstar ブラウザ

Southstar は、動作し続けたままモジュールごとに Rust へ移植された Nordstjernen です。2026年10月以降、独自のコードはすべて Rust で書かれており — 約 163 のクレートに約 385,000 行 — Cargo だけでビルドできます。ページの JavaScript は Boa で実行されます。これは JIT を持たず、test262 のすべてに合格する Rust 製インタープリターで、HTML の解析、テキストレイアウト、TLS、WebAssembly も Rust で実装されています。Southstar 1.0.9 は Microsoft Store と crates.io で公開されており、Linux 向けパッケージは GitHub にあります。移植の経緯は docs/rust-port.md にまとめています。

仕様

3 つのブラウザ、1 つのクリーンルームエンジンの系譜。Nordstjernen はマルチタブのフラッグシップブラウザ、Northstar は GPL ライセンスのミニマルなシングルプロセス版、Southstar は同じブラウザを Rust で書き直したものです。
