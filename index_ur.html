Nordstjernen ویب براؤزر

Nordstjernen ایک خودمختار ویب براؤزر ہے جو C میں لکھا گیا ہے، 2026 میں شروع ہوا اور HTML اور CSS معیارات کی حمایت پر توجہ دیتا ہے۔ یہ Windows، macOS اور Linux پر چلتا ہے، اور اس کے بلڈز Android، FreeBSD، NetBSD اور JVM کے لیے بھی دستیاب ہیں۔ Nordstjernen ناروے میں بنایا گیا ہے۔

Nordstjernen 1.0.51 جاری کر دیا گیا — CSS Typed OM، مشترکہ میموری کے ساتھ WebAssembly تھریڈز، لنکس سمیت PDF ایکسپورٹ، اور ایک AppImage۔ ریلیز نوٹس »

Northstar 1.0.26 جاری کر دیا گیا — WebGL 1 اور 2، کام کرتا ہوا Gmail، سیکیورٹی اصلاحات اور ایک AppImage۔ Northstar کا تعارف · ریلیز نوٹس »

Southstar 1.0.11 جاری کر دیا گیا — اسٹریمنگ HTML پارسر، چھوٹا DOM اور ریئل ٹائم Web Audio۔ Southstar کا تعارف · ریلیز نوٹس »

HTML معیار۔ رویے کو کسی دوسرے براؤزر سے نہیں بلکہ تصریح کے متن سے، حصہ بہ حصہ، پرکھا جاتا ہے: WHATWG HTML تصریح کی 141 مدیں مکمل طور پر نافذ ہیں، 31 جزوی طور پر، اور کوئی بھی غائب نہیں۔ یہ Web Platform Tests کے html/، dom/ اور url/ ذیلی ٹیسٹس میں سے 91.5% اور css/ میں سے 73.2% پاس کرتا ہے (اکتوبر 2026) — دیکھیے docs/HTML-compatibility.md۔

محفوظ۔ ہر ٹیب اپنے الگ سینڈ باکس شدہ رینڈرر پروسیس میں چلتا ہے — Linux پر seccomp + Landlock، macOS پر Seatbelt پروفائل، اور Windows پر پروسیس مٹیگیشن پالیسیاں۔ نہ JavaScript انجن میں JIT ہے اور نہ WebAssembly انجن میں۔

سادگی۔ براؤزر میں منصوبے کے اپنے C کوڈ اور ہیڈرز کی تقریباً 296,000 لائنیں ہیں، شامل کی گئی بیرونی لائبریریوں اور خودکار طور پر بنائی گئی فائلوں کے علاوہ — اتنا چھوٹا کہ ایک شخص شروع سے آخر تک پڑھ کر اس کا آڈٹ کر سکے۔

بھرپور صلاحیتیں۔ محفوظ Rust میں لکھا گیا اپنا HTML5 پارسر، ہیپ کے لحاظ سے مضبوط کیا گیا QuickJS، تھریڈز کے ساتھ WebAssembly، CSS Typed OM، WebGL 1 & 2 اور WebGPU، Service Workers اور Streams۔ ان لائن <video> — MPEG-1، WebM، اور آپریٹنگ سسٹم کے ڈیکوڈرز کے ذریعے MP4 — HLS، DASH اور کیپشنز کے ساتھ، نیز SMIL اینیمیشن والا SVG، MathML اور PDF.js ویوور۔

آٹومیشن۔ nordstjernen --mcp کسی مقامی ایجنٹ کو ونڈو پڑھنے اور چلانے دیتا ہے — اجازت دینے تک بند، صرف لوپ بیک پر، اور ٹوکن کے ذریعے تصدیق کے ساتھ — اور --webdriver Selenium اور دیگر ٹیسٹ فریم ورکس کے لیے W3C WebDriver فراہم کرتا ہے۔ براؤزر میں خود کوئی AI اسسٹنٹ نہیں ہے۔

پرنٹنگ۔ Ctrl+P صفحے کو @media print، @page اور صفحہ بندی کے وقفوں کے مطابق صفحات میں تقسیم کرتا ہے اور انہیں آپریٹنگ سسٹم کے اپنے پرنٹ ڈائیلاگ کے حوالے کر دیتا ہے۔ --export=pdf:FILE انہی صفحات کو، لنکس سمیت، پرنٹر کے بغیر PDF میں لکھ دیتا ہے۔

تیز رفتار۔ web-text-lib، جو منصوبے کے اندر رکھا گیا Pango کا فورک ہے، شیپ کیے گئے متن کو مختلف لے آؤٹس میں کیش کرتا ہے اور جدولوں سے بھرے صفحات پر لے آؤٹ کا وقت 24% کم کر دیتا ہے۔ HTTP/3 اپ گریڈز کنکشن ٹائم آؤٹ پر رکنے کے بجائے alt-svc کیش سے گزرتے ہیں: Acid3 کو لوڈ ہونے میں 15.5 کے بجائے 2.2 سیکنڈ لگتے ہیں۔

نجی۔ نہ ٹیلی میٹری، نہ اپ ڈیٹ پنگز، اور کلائنٹ ہنٹس میں نام Chrome کا نہیں بلکہ Nordstjernen کا ہوتا ہے۔ تھرڈ پارٹی کوکیز بلاک ہیں، لنکس سے ٹریکنگ پیرامیٹرز ہٹا دیے جاتے ہیں، اور سیف براؤزنگ Google کو صرف 4 بائٹ کا ہیش پریفکس بھیجتی ہے، پتہ کبھی نہیں۔

آزاد سافٹ ویئر۔ 1.0.28 سے Nordstjernen دوہرے لائسنس کے تحت ہے: آپ اپنی مرضی سے اسے GNU GPL، ورژن 3 یا بعد کے تحت، یا Nordstjernen Source License 1.0 کے تحت استعمال، تبدیل اور دوبارہ تقسیم کر سکتے ہیں۔

Northstar براؤزر

Northstar Nordstjernen کا سادہ بہن بھائی ہے، جو GNU GPL، ورژن 3 یا بعد کے تحت لائسنس یافتہ ہے: ایک ونڈو، ایک صفحہ اور ایک پروسیس، اصل C کی تقریباً 234,000 لائنوں میں بنایا گیا۔ اس میں ٹیبز، فی ٹیب رینڈرر پروسیسز اور WebGPU شامل نہیں، لیکن WebGL 1 اور 2، اسٹریمنگ ویڈیو، پرنٹنگ، PDF.js ویوور، WebExtensions، Google سیف براؤزنگ اور 40 زبانوں میں UI موجود ہے، اور Linux پر یہ Landlock اور seccomp سینڈ باکس کے اندر چلتا ہے۔ Linux اس کا بنیادی پلیٹ فارم ہے؛ یہ macOS، BSD سسٹمز اور Windows پر بھی چلتا ہے، اور Windows کے لیے Microsoft Store پر دستیاب ہے۔

Northstar کی مکمل دستاویزات پڑھیں » · یا تینوں براؤزرز کے فرق جاننے کے لیے نیچے دیا گیا موازنہ جدول دیکھیں۔

Southstar براؤزر

Southstar دراصل Nordstjernen ہے جسے چلتے رہنے کے دوران ماڈیول بہ ماڈیول Rust میں منتقل کیا گیا: اکتوبر 2026 سے اس کا اپنا تمام کوڈ Rust میں ہے — 164 کریٹس میں تقریباً 390,000 لائنیں — اور یہ صرف Cargo سے بنتا ہے۔ صفحات کا JavaScript Boa پر چلتا ہے، جو JIT کے بغیر Rust انٹرپریٹر ہے اور test262 کے تمام ٹیسٹ پاس کرتا ہے، اور HTML پارسنگ، ٹیکسٹ لے آؤٹ، TLS اور WebAssembly بھی Rust ہی میں ہیں۔ Southstar 1.0.11 Microsoft Store اور crates.io پر دستیاب ہے، اور اس کے Linux پیکجز GitHub پر ہیں؛ منتقلی کیسے کی گئی، یہ docs/rust-port.md میں درج ہے۔

Weststar براؤزر

Weststar اس خاندان کا سب سے نیا رکن ہے، جو نومبر 2026 میں شروع ہوا: Northstar کا ایک فورک جس میں GTK 4 انٹرفیس اور Cairo رینڈرر بدل دیے گئے ہیں۔ اس کی ونڈو SDL3 ہے، اور صفحات، براؤزر کا انٹرفیس اور متن Weststar کے اپنے 2D ریسٹرائزر سے بنائے جاتے ہیں؛ صفحات کا انجن Northstar ہی کا ہے۔ یہ Linux اور Windows پر چلتا ہے، GNU GPL، ورژن 3 یا بعد کے تحت لائسنس یافتہ ہے، اور فی الحال اس میں WebGL، WebGPU، <video> اور پرنٹنگ شامل نہیں۔ ابھی کوئی ریلیز نہیں؛ منتقلی کی پیش رفت docs/porting-to-sdl.md میں درج ہے۔

Nordstjernen ویب براؤزر کی جدتوں کے بارے میں مزید پڑھیں۔
