Nordstjernen Web Browser

Nordstjernen is a web browser, written from scratch in C, focused on supporting the HTML and CSS standards. It runs on Windows, macOS and Linux, with builds for Android, FreeBSD, NetBSD and the JVM.

HTML Standard. Behaviour is measured against the spec text, section by section, not against another browser: 141 WHATWG HTML spec rows fully implemented, 31 partial and none absent. It passes 91.5% of the Web Platform Tests html/, dom/ and url/ subtests and 73.2% of css/ (October 2026) — see docs/HTML-compatibility.md.

Secure. Each tab runs in its own sandboxed renderer process — seccomp + Landlock on Linux, a Seatbelt profile on macOS, process mitigation policies on Windows. There is no JIT in either the JavaScript or the WebAssembly engine.

Minimalism. The core engine is about 268,000 lines of project C and headers, excluding the vendored libraries and generated assets — small enough for one person to read and audit end-to-end.

Capable. Its own HTML5 parser in safe Rust, a heap-hardened QuickJS, WebAssembly, WebGL 1 & 2 and WebGPU, Service Workers and Streams. Inline <video> — MPEG-1, WebM, and MP4 through the operating system’s decoders — with HLS, DASH and captions, plus SVG with SMIL animation, MathML and a PDF.js viewer.

Automation. nordstjernen --mcp lets a local agent read and drive the window — off until allowed, loopback only, token-authenticated — and --webdriver serves W3C WebDriver for Selenium and other test frameworks. The browser itself has no AI assistant.

Prints. Ctrl+P paginates the page with @media print, @page and page breaks and hands the sheets to the operating system’s own print dialog. --dump=print:FILE writes the same pages to a PDF without a printer.

Fast. web-text-lib, the in-tree Pango fork, caches shaped text across layouts and cuts layout time by 24% on table-heavy pages. HTTP/3 upgrades go through the alt-svc cache instead of stalling on a connect timeout: Acid3 loads in 2.2 seconds rather than 15.5.

Private. No telemetry, no update pings, and client hints that name Nordstjernen rather than Chrome. Third-party cookies are blocked, tracking parameters stripped from links, and Safe Browsing sends Google only a 4-byte hash prefix, never the address.

Free software. Since 1.0.28 Nordstjernen is dual-licensed: use, modify and redistribute it under the GNU GPL, version 3 or later, or under the Nordstjernen Source License 1.0, at your option.

the Northstar browser

Northstar is the minimalist sibling of Nordstjernen, licensed under the GNU GPL, version 3 or later: one window, one page and one process, built from the same clean-room engine in about 219,000 lines of original C. It leaves out tabs, per-tab renderer processes, WebGL and WebGPU, but keeps streaming video, printing, WebExtensions, Google Safe Browsing and a UI in 40 languages, behind a Landlock and seccomp sandbox on Linux. It runs on Linux, macOS and Windows, where it is on the Microsoft Store.

the Southstar browser

Southstar is Nordstjernen ported to Rust, module by module, while it kept running: since October 2026 all of its own code is Rust — about 385,000 lines in some 163 crates — built with Cargo alone. Page JavaScript runs on Boa, a Rust interpreter with no JIT that passes all of test262, and HTML parsing, text layout, TLS and WebAssembly are Rust too. Southstar 1.0.9 is on the Microsoft Store, on crates.io, and has Linux packages on GitHub; how the port was done is in docs/rust-port.md.

specifications

Three browsers, one clean-room engine lineage. Nordstjernen is the flagship multi-tab browser; Northstar is the minimalist GPL-licensed single-process edition; Southstar is the same browser rewritten in Rust.
