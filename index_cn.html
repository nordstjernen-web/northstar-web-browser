Nordstjernen 网页浏览器

Nordstjernen 是一款用 C 语言从零编写的网页浏览器，专注于支持 HTML 和 CSS 标准。它可在 Windows、macOS 和 Linux 上运行，并提供 Android、FreeBSD、NetBSD 和 JVM 版本。Nordstjernen 在挪威打造。

Nordstjernen 1.0.47 已发布 — 用安全 Rust 编写的自有 HTML5 解析器、经过堆加固的 QuickJS、PDF.js 查看器以及 SVG SMIL 动画。发行说明 »

Northstar 1.0.23 已发布 — SVG SMIL 动画、Windows 显示缩放以及安全修复。关于 Northstar · 发行说明 »

Southstar 1.0.9 已发布 — 纯 Java 界面外壳、SVG SMIL 动画，并修复了一次安全审计发现的全部问题。关于 Southstar · 发行说明 »

HTML 标准。浏览器的行为逐节对照规范文本来衡量，而不是以其他浏览器为参照：WHATWG HTML 规范中有 141 项已完全实现，31 项部分实现，没有缺失项。它的通过率达到 91.5%，涵盖 Web Platform Tests 中的 html/、dom/ 和 url/ 子测试；css/ 的通过率为 73.2%（2026 年 10 月）— 详见 docs/HTML-compatibility.md。

安全。每个标签页都在各自的沙箱化渲染进程中运行 — Linux 上使用 seccomp + Landlock，macOS 上使用 Seatbelt 配置文件，Windows 上使用进程缓解策略。JavaScript 引擎和 WebAssembly 引擎均不含 JIT。

极简。核心引擎约有 268,000 行项目自有的 C 代码和头文件，不含内置的第三方库和生成的资源 — 小到一个人就能从头到尾通读并审计。

功能完备。用安全 Rust 编写的自有 HTML5 解析器、经过堆加固的 QuickJS、WebAssembly、WebGL 1 & 2 与 WebGPU、Service Workers 和 Streams。内联 <video> — MPEG-1、WebM，以及借助操作系统解码器播放的 MP4 — 支持 HLS、DASH 和字幕，此外还有支持 SMIL 动画的 SVG、MathML 和 PDF.js 查看器。

自动化。nordstjernen --mcp 让本地智能体读取并操控窗口 — 默认关闭、需经允许，仅限回环地址，并采用令牌认证 — 而 --webdriver 为 Selenium 及其他测试框架提供 W3C WebDriver 服务。浏览器本身不含 AI 助手。

打印。Ctrl+P 按照 @media print、@page 和分页符对页面分页，并将各页交给操作系统自带的打印对话框。--dump=print:FILE 无需打印机即可将同样的页面写入 PDF。

快速。web-text-lib 是树内维护的 Pango 分支，可在多次布局之间缓存已完成塑形的文本，使表格密集页面的布局时间缩短 24%。HTTP/3 升级通过 alt-svc 缓存进行，不会卡在连接超时上：Acid3 只需 2.2 秒即可加载完成，而不是 15.5 秒。

注重隐私。没有遥测，没有更新检查请求，客户端提示中标明的是 Nordstjernen 而不是 Chrome。第三方 Cookie 会被阻止，链接中的跟踪参数会被移除，安全浏览只向 Google 发送 4 字节的哈希前缀，绝不发送网址。

自由软件。自 1.0.28 起，Nordstjernen 采用双重许可：您可以任选 GNU GPL 第 3 版或更高版本，或 Nordstjernen Source License 1.0，依其条款使用、修改和再分发本软件。

Northstar 浏览器

Northstar 是 Nordstjernen 的极简版姊妹浏览器，采用 GNU GPL 第 3 版或更高版本许可：一个窗口、一个页面、一个进程，基于同一个净室引擎，由约 219,000 行原创 C 代码构建而成。它省去了标签页、按标签页划分的渲染进程、WebGL 和 WebGPU，但保留了流媒体视频、打印、WebExtensions、Google 安全浏览以及 40 种语言的界面，并在 Linux 上运行于 Landlock 和 seccomp 沙箱之中。它可在 Linux、macOS 和 Windows 上运行，Windows 版已上架 Microsoft Store。

Southstar 浏览器

Southstar 是 Nordstjernen 的 Rust 移植版，在保持可运行的同时逐个模块完成了移植：自 2026 年 10 月起，它自身的全部代码均为 Rust — 约 385,000 行，分布在约 163 个 crate 中 — 仅用 Cargo 即可构建。页面中的 JavaScript 运行在 Boa 上，这是一个不含 JIT、通过全部 test262 测试的 Rust 解释器；HTML 解析、文本布局、TLS 和 WebAssembly 也都由 Rust 实现。Southstar 1.0.9 已上架 Microsoft Store 和 crates.io，并在 GitHub 上提供 Linux 软件包；移植的具体过程请参阅 docs/rust-port.md。

规格

三款浏览器，同一脉相承的净室引擎。Nordstjernen 是多标签页的旗舰浏览器；Northstar 是采用 GPL 许可的极简单进程版本；Southstar 则是用 Rust 重写的同一款浏览器。
