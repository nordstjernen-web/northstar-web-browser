# Northstar Web Browser documentation

Developer documentation for the **Northstar Web Browser** (open-source GPL
edition) — a minimalist browser written from scratch in C with GTK 4 and
libcurl, carrying no upstream browser engine.

## Contents

- **[architecture.md](architecture.md)** — the process and thread model
  (single-process in this edition), the page-load pipeline, and a map of
  which source file owns which job. Its diagram, `architecture.svg`, is
  generated by `scripts/gen-architecture.py`; edit the script, not the
  SVG.
- **[building.md](building.md)** — dependencies per platform, the
  meson/ninja build, meson options, the command line and headless mode,
  configuration and environment variables, and the smoke and render-test
  fixtures.
- **[vscode.md](vscode.md)** — building, running and debugging in Visual
  Studio Code with the workspace in `.vscode/`, on Linux, macOS and
  Windows.
- **[compliance.md](compliance.md)** — where the engine stands against the
  HTML and CSS specifications, how to reproduce the web-platform-tests
  scores, and the known structural gaps.
- **[quickjs.md](quickjs.md)** — the choice between quickjs-ng (the
  default) and Fabrice Bellard's original QuickJS (`-Djs_engine=quickjs`):
  how the original is built and patched, the API adapter, and what differs.
- **[js-engine-comparison.md](js-engine-comparison.md)** — the two engine
  builds measured side by side: build cost, startup, Octane, DOM and
  built-in micro-benchmarks, Speedometer, web-platform-tests and language
  features.
- **[cve-2026-85046.md](cve-2026-85046.md)** — why the actively exploited
  V8 JIT type confusion CVE-2026-85046 does not apply to Northstar Web Browser: no V8,
  no JIT, no elements-kind maps, no write barriers.

## Scope of this edition

This is the minimalist GPL desktop edition. It is single-process (the
engine runs in the shell process, on its own thread), targets Linux
(primary), macOS and Windows, and deliberately omits tabs, renderer
processes, WebGL/WebGPU, the PDF viewer, local-AI features, and the
embeddable-library API. `<video>` decodes MPEG-1 and nothing else, in the
browser process. See [../README.md](../README.md) for the project scope
and the no-AI contribution policy.
