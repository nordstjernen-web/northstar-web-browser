Latest release: Nordstjernen 1.0.45 — released 8 November 2026, with a portable Linux zip, a Debian/Ubuntu package for each of Ubuntu 26.04 and Debian 13 and an RPM for Fedora 45, each built against that release’s own libraries, and a notarised macOS disk image for Apple silicon. It also installs with npm install -g nordstjernen-browser or pip install nordstjernen-browser, which build the release source against your system’s libraries. Nordstjernen is dual-licensed: use it under the GNU GPL version 3 or later, or under the Nordstjernen Source License 1.0, at your option. full release notes »

The most recent Alpine, openSUSE, Java and Windows zip packages are from Nordstjernen 1.0.23 — released 8 August 2026. read the announcement » · full release notes »

Nordstjernen is also available on the Microsoft Store and on Google Play for Android.

Looking for the minimalist GPL edition? Northstar 1.0.22 — released 8 November 2026 — is on GitHub as source (1.0.22.tar.gz), and on the Microsoft Store for Windows. The most recent Linux binaries are from 1.0.7: a portable zip, an AppImage and a Debian package. all Northstar downloads »

Interested in Rust? Southstar 1.0.8 — released 8 November 2026 — is the browser rewritten in Rust. It is on the Microsoft Store for Windows, and has a portable Linux zip and .deb packages for Debian 13, Debian forky, Debian sid, Ubuntu 24.04 and Ubuntu 26.04; npm install -g southstar-browser or cargo install southstar build it from source elsewhere (see GitHub).
